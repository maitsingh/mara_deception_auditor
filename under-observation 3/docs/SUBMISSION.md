# Submission checklist

## Required submissions

- [ ] Publish and verify the artifact or repository URL.
- [ ] **Upload `poster/Under_Observation_Poster_24x36.pdf` to Canvas as the poster submission. A PDF stored in GitHub does not replace that upload.**
- [ ] Rehearse the presentation with a timer. Aim for four minutes and stop by 4:30, leaving a buffer under five minutes.
- [ ] If you are an online student, submit a video no longer than five minutes that demonstrates the project.

## Presentation order

1. Explain the Responsible AI need before the game mechanics.
2. Show the intervention and what the retained records can establish.
3. Present one behavioral comparison and its uncertainty.
4. Explain the XAI technique and its limited fidelity.
5. Use one short recorded episode, then state the contribution and next step.

Use `PRESENTATION.md`; do not attempt to narrate every table or all 96 notes.
